# 部署上线

## 获取服务器

在对应的云平台上购买服务器，我购买的是2核2GB的云服务器ECS，因为是首次购买，只需不到1张。

通过`PING`测试是否有响应。

## 安装 Docker

```bash
sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
echo '/swapfile none swap sw 0 0' | sudo tee -a /etc/fstab

sudo apt-get update
sudo apt-get install -y docker.io docker-compose-v2
sudo systemctl enable --now docker
docker --version
docker compose version
```

然后给 Docker 配镜像加速。打开阿里云控制台，搜索「容器镜像服务」，进入「镜像工具」→「镜像加速器」，复制你的加速器地址。然后在服务器上执行，把地址换成你复制的那一条：

```bash
sudo mkdir -p /etc/docker
sudo tee /etc/docker/daemon.json <<-'EOF'
{
  "registry-mirrors": ["https://你的加速器地址"]
}
EOF
sudo systemctl daemon-reload
sudo systemctl restart docker
docker info | grep -A 3 "Registry Mirrors"
```

## 拉镜像

拉 `MySQL` 和 `Redis` 镜像：

```powershell
docker pull mysql:8.4
docker pull redis:8
```

可能镜像拉取不成功，也可以不用 `docker` 拉取：

```bash
sudo apt-get update
sudo apt-get install -y mysql-server redis-server
sudo systemctl enable --now mysql redis-server
mysql --version
redis-server --version
```

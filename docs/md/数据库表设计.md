# 题津舟-智能面试刷题平台

## 数据库表的设计

### 用户表

#### sql语句

```mysql
create table if not exists app_user
(
    id            bigint        not null auto_increment comment 'id',
    user_account  varchar(64)   not null comment '账号',
    user_password varchar(255)  not null comment '密码哈希，不存明文',
    user_name     varchar(64)   null comment '用户昵称',
    user_avatar   varchar(1024) null comment '用户头像',
    user_profile  varchar(512)  null comment '用户简介',
    user_role     varchar(16)   not null default 'user' comment '角色：user/admin',
    user_status   tinyint       not null default 0 comment '状态：0正常 1封禁',
    create_time   datetime      not null default current_timestamp comment '创建时间',
    update_time   datetime      not null default current_timestamp on update current_timestamp comment '更新时间',
    is_delete     bigint        not null default 0 comment '0未删除，删除后写入本行id',
    primary key (id),
    unique key uk_user_account (user_account, is_delete),
    constraint chk_user_role check (user_role in ('user', 'admin')),
    constraint chk_user_status check (user_status in (0, 1))
) engine = InnoDB
  default charset = utf8mb4
  collate = utf8mb4_0900_ai_ci
  comment = '用户';
```



editTime 和 updateTime 的区别是：

- editTime 表示用户编辑个人信息的时间（需要业务代码来更新）
- updateTime 表示这条用户记录任何字段发生修改的时间（由数据库自动更新）

#### 扩展设计

- 扩展公众号登录：
  - unionId、mpOpenId 可以实现公众号登录的。每个微信用户在同一家公司（主体）的 unionId 是唯一的，在同一个公众号的 mpOpenId 是唯一的。

- 扩展会员功能：
  - vipExpireTime：会员过期时间，如果是null，就说明不是会员
  - vipCode：会员兑换码
  - vipNumber：会员编号

- 扩展用户邀请功能：
  - shareCode：分享码
  - inviteUser：邀请用户id

### 题库表

#### sql语句

```mysql
create table if not exists question_bank
(
    id          bigint        not null auto_increment comment 'id',
    title       varchar(256)  not null comment '标题',
    description text          null comment '描述',
    picture     varchar(2048) null comment '图片',
    user_id     bigint        not null comment '创建用户 id',
    create_time datetime      not null default current_timestamp comment '创建时间',
    update_time datetime      not null default current_timestamp on update current_timestamp comment '更新时间',
    is_delete   tinyint       not null default 0 comment '是否删除：0未删除 1已删除',
    primary key (id),
    constraint chk_question_bank_delete check (is_delete in (0, 1))
) engine = InnoDB
  default charset = utf8mb4
  collate = utf8mb4_0900_ai_ci
  comment = '题库';
```

#### 扩展设计

- 题库审核功能：
  - reviewStatus：审核状态 0-待审核 1-通过 2-拒绝
  - reviewMessage：审核信息
  - reviewId：审核人 Id
  - reviewTime：审核时间
- 题库排序功能：
  - priority：根据字段大小排序，还可以用于快速实现题库精选和置顶功能。比如1000表示精选，10000表示置顶
- 题库浏览功能：
  - viewNum：浏览量
  - 如果要实现用户浏览数，还需额外的题库浏览记录表

### 题目表

#### sql语句

```mysql
create table if not exists question
(
    id          bigint       not null auto_increment comment 'id',
    title       varchar(256) not null comment '标题',
    content     text         null comment '内容',
    tags        json         null comment '标签列表（json 数组）',
    answer      text         null comment '推荐答案',
    user_id     bigint       not null comment '创建用户 id',
    status      tinyint      not null default 0 comment '状态：0草稿 1已发布',
    create_time datetime     not null default current_timestamp comment '创建时间',
    update_time datetime     not null default current_timestamp on update current_timestamp comment '更新时间',
    is_delete   tinyint      not null default 0 comment '是否删除：0未删除 1已删除',
    primary key (id),
    constraint chk_question_status check (status in (0, 1)),
    constraint chk_question_delete check (is_delete in (0, 1))
) engine = InnoDB
  default charset = utf8mb4
  collate = utf8mb4_0900_ai_ci
  comment = '题目';
```

#### 扩展设计

- 题目审核功能：
  - reviewStatus：审核状态 0-待审核 1-通过 2-拒绝
  - reviewMessage：审核信息
  - reviewId：审核人 Id
  - reviewTime：审核时间
- 评价指标功能：
  - viewNum：浏览量
  - thumbNum：点赞数
  - favourNum：收藏数
- 题目排序功能：
  - priority：根据字段大小排序，还可以用于快速实现题目精选和置顶功能。比如1000表示精选，10000表示置顶
- 版权说明功能：
  - source：题目来源
- 会员可见功能：
  - needVip：是否仅会员可见 0:非会员可见 1:仅会员可见

### 题库题目关系表

#### sql语句

```mysql
create table if not exists question_bank_question
(
    id               bigint   not null auto_increment comment 'id',
    question_bank_id bigint   not null comment '题库 id',
    question_id      bigint   not null comment '题目 id',
    user_id          bigint   not null comment '创建用户 id',
    create_time      datetime not null default current_timestamp comment '创建时间',

    index idx_question_id (question_id)
) engine = InnoDB
  default charset = utf8mb4
  collate = utf8mb4_0900_ai_ci
  comment = '题库题目';
```

#### 扩展设计

- 排序功能：
  - questionOrder：题目顺序

### 用户刷题记录表

签到不建表，按月存在 Redis Bitmap，见 [用户签到记录日历](用户签到记录日历.md)。刷题流水用本表。同一用户、同一题、同一天只保留一行。不做逻辑删除：题目删除后，当天题数仍按本表计算。

#### sql语句

```mysql
create table if not exists user_practice_record
(
    id            bigint   not null auto_increment comment 'id',
    user_id       bigint   not null comment '用户 id',
    question_id   bigint   not null comment '题目 id',
    practice_date date     not null comment '刷题日期，按 Asia/Shanghai 自然日',
    create_time   datetime not null default current_timestamp comment '创建时间',
    primary key (id),
    unique key uk_user_question_date (user_id, question_id, practice_date),
    index idx_user_date (user_id, practice_date)
) engine = InnoDB
  default charset = utf8mb4
  collate = utf8mb4_0900_ai_ci
  comment = '用户刷题记录';
```
